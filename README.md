# temperature-monitoring-alert-system
Temperature Monitoring and Alert System

Project Overview

This project focuses on designing and simulating a temperature monitoring and alert system using an LM35 temperature sensor and an LM393 comparator.

Objective

To generate an LED alert when the sensed temperature crosses a nominal threshold of 30°C.

Components and Tools

- LM35 Temperature Sensor
- LM393 Comparator
- Resistors and feedback network for hysteresis
- RFSpice simulation software

Work Completed

- Designed the analog temperature-monitoring circuit.
- Calculated sensor and reference voltages.
- Implemented a hysteresis feedback circuit in RFSpice.
- Observed and documented simulation waveforms.
